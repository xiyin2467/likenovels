# 竞品横向对比：GoodNovel vs iReader

> 数据来源：`_raw/goodnovel.json`、`_raw/ireader.json`。结论用于指导我们自己出海小说 App 的产品规划。

## 0. 一句话结论

**GoodNovel 是真正的出海网文产品，应作为主要对标对象；iReader（本包为国内版）展示了成熟阅读内核与"国内重运营"打法，作为体验借鉴与出海反面参照。**

## 1. 基础信息对比（事实）

| 维度 | GoodNovel | iReader（国内版） |
|---|---|---|
| 包名 | `com.read.goodnovel` | `com.chaozh.iReaderFree`（`com.zhangyue.iReader`） |
| 版本 | 2.5.8.1168 | 8.7.3.1 |
| targetSdk | 33（较新，合规） | 30（偏旧） |
| 主体 | 新加坡（SG） | 中国掌阅 |
| ABI | 全架构（含 x86） | arm64/armeabi（偏国内机型） |
| Activity 数 | 157 | 298 |
| Service 数 | 23 | 60 |
| 权限数 | 22（克制） | 52（激进） |
| 加固 | 无（仅 1 个原生库） | 有（加壳 + 多安全库），中央目录缺失 |

## 2. 市场与生态对比

| 维度 | GoodNovel | iReader（国内版） |
|---|---|---|
| 目标市场 | 全球多区域（90+ 语言） | 中国大陆为主 |
| 广告 | AppLovin MAX 聚合 + AdMob/Unity/ironSource/Mintegral/Vungle/Fyber | 穿山甲/快手/广点通/百度/Sigmob 等国内聚合 + AdMob/华为 |
| 支付 | Google Play Billing | 支付宝/微信/QQ 钱包 |
| 推送 | FCM（单一，合规） | 小米/Vivo/魅族/OPPO/华为/个推/友盟全家桶 |
| 登录 | Google/Facebook/邮箱 | 微信/QQ/微博/抖音/一键登录 |
| 归因 | AppsFlyer + Adjust | 友盟 + 字节 APM（国内体系） |
| 埋点 | 神策 | 神策（定制） |

> 启示：出海技术栈 = **FCM + Google Billing + AppLovin/AdMob + AppsFlyer/Adjust + 三方(Google/Facebook)登录**，与国内栈完全不同，不能复用国内方案。

## 3. 内容与形态对比

| 维度 | GoodNovel | iReader |
|---|---|---|
| 文字小说 | ✅ 核心（网文/短故事） | ✅ 网文 + 出版书 |
| 漫画 | ✅ | ✅ |
| 有声/TTS | ✅（ExoPlayer 播放器） | ✅ 强（TTS + AI 电台 + AI 朗读） |
| PDF/EPUB/文档 | ❌（专注网文形态） | ✅ 强（PDF/EPUB/Story） |
| UGC 创作 | ✅ 完整作者中心 | 书单为主，创作弱 |
| 阅读内核深度 | 中（够用，偏网文） | 高（字体/皮肤/护眼/笔记/云同步/进度） |

> 启示：GoodNovel **窄而深地服务网文变现**；iReader **宽而全地服务泛阅读**。出海初期应学 GoodNovel 的"窄而深"。

## 4. 变现模式对比

| 维度 | GoodNovel | iReader |
|---|---|---|
| 主收入 | 金币解锁章节（内购充值） | 按书/章付费 + 会员订阅 |
| 广告变现 | 激励视频解锁/赚币（聚合） | 激励视频得代金券 + 信息流 |
| 免费留存 | 等待解锁（Wait-to-unlock） | 自动购买 + 代金券 |
| 二级货币 | Gems / 兑换 | 书币 / 代金券 |

> 启示：出海网文**标准变现三件套** = 金币内购解锁 + 激励广告 + 等待解锁，直接对标 GoodNovel。

## 5. 合规与工程对比

- **GoodNovel**：targetSdk 33、权限克制、单一 FCM 推送、无加固、全架构支持 —— 出海合规友好、工程相对轻。
- **iReader**：targetSdk 30、52 项含激进权限（全盘存储/悬浮窗/应用内安装/日历/自启动）、全厂商推送、强加固 —— 国内打法，**直接出海会触碰 Google Play 政策红线**。

## 6. 对我们做出海小说 App 的启示（汇总）

1. **对标 GoodNovel，而非 iReader**：iReader 这个包是国内版，技术与合规都不适配海外。
2. **MVP 聚焦单形态**：文字小说 + 金币解锁 + 激励广告 + 等待解锁，先跑通最小变现闭环（YAGNI）。
3. **出海技术栈固定**：FCM 推送、Google Play Billing、AppLovin/AdMob 广告聚合、AppsFlyer/Adjust 归因、Google/Facebook 登录、自有埋点。
4. **本地化是入场券**：从架构第一天就支持多语言 + 多币种（GoodNovel 90+ 语言是范例）。
5. **阅读体验底盘借鉴 iReader**：字体/主题/护眼/进度/书签等阅读器细节要做扎实。
6. **合规优先**：targetSdk 取最新、权限最小化、推送只用 FCM、避免悬浮窗/全盘存储/应用内安装等高风险权限。
7. **第二阶段能力（暂不做）**：漫画、有声/TTS、AI 朗读、UGC 作者中心、社区——验证留存与付费后再投入。

## 7. 数据可信度与缺口

- GoodNovel：未加固，androguard 完整解析，结论可信度高。
- iReader：加固 + 中央目录缺失，经流式解析 + AXML 还原，组件/SDK 事实可信，细粒度功能为类名推断。
- 两者均未做动态运行/抓包；定价、广告频次、解锁节奏等运营细节需后续实机验证。

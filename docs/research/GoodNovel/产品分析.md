# GoodNovel 产品分析

> 基于 APK 静态结构（`docs/research/_raw/goodnovel.json`）+ 网文出海产品认知。
> **事实**=来自 APK；**推断**=产品逻辑推测，落地前需运行验证。

## 1. 产品定位

GoodNovel 是一款**面向全球的网络小说平台**（新加坡主体），主打英文原创/翻译网文，兼具**漫画**与**有声书**形态，并开放**作者创作**。商业模式为「免费试读 + 金币解锁章节 + 激励广告」。

目标人群（推断）：欧美及多语言市场的网文重度读者（女频言情、霸总、狼人、System/重生等品类为主），以及希望变现的网文作者。

## 2. 功能地图（按用户视角）

- **账号**：邮箱登录、Google 登录、Facebook 登录、个人资料编辑。
- **发现**：书城运营位、分类（Genres）、标签（Tag）、榜单（实时/历史榜）、搜索。
- **阅读**：文字阅读器（目录、章末推荐）、漫画阅读器、有声播放器（含试听）。
- **付费**：单章解锁、批量订购、等待解锁（Wait-to-unlock）、白名单解锁、充值、钱包、Gems、兑换、消费记录。
- **社区**：社区主页、发帖、帖子详情、评论（书评/段评）、关注/粉丝、Top 粉丝榜。
- **活动**：赛事（Contest）、获奖书单。
- **创作（作者中心）**：创建作品 → 写章节 → 生成封面 → 数据统计 → 作品推广。
- **消息**：站内信、系统消息、推送管理。
- **设置**：语言切换、条款隐私、推送管理、更新。

## 3. 核心用户流程（推断）

1. **冷启动转化**：Splash → Guide 引导（性别/口味选择，推断）→ 进首页书城。
2. **阅读到付费漏斗**：书城/榜单 → 书籍详情 → 阅读器免费章 → 触达付费墙 → 单章解锁 / 批量订购 / 看激励广告解锁 / 等待解锁（定时免费）。
3. **充值闭环**：解锁触发余额不足 → Recharge（Google Billing 充值金币）→ Wallet 记录。
4. **留存玩法**：等待解锁（Wait-to-unlock，养成定时回访）、社区互动、赛事、推送召回（FCM）。
5. **创作侧**：作者中心创建作品并发布章节，平台抽成分发。

## 4. 变现模式（事实支撑 + 推断）

- **金币解锁**（事实：`UnlockChapterActivity`/`BulkOrderActivity`/`RechargeActivity`/`WalletActivity` + Google Billing）：核心收入，章节按金币计费，充值套餐购买金币。
- **激励广告**（事实：AppLovin MAX 聚合 + Unity/ironSource/Mintegral/Vungle/Fyber 激励视频）：看广告免费解锁/赚金币，作为不付费用户的变现与转化通道。
- **等待解锁**（事实：`WaitUnlockListActivity`）：定时解锁机制，平衡免费体验与付费意愿。
- **Gems/兑换**（事实：`GemsDetailActivity`/`ExchangeActivity`）：二级虚拟货币/打赏体系（推断用于社区打赏或活动激励）。

> 推断的变现组合：**内购金币为主、激励广告为辅、等待解锁做免费留存**，三者叠加最大化 ARPU 与 DAU。

## 5. 增长与留存设计（推断）

- 归因双保险：AppsFlyer + Adjust，支撑大规模买量投放与渠道 ROI 核算。
- 行为埋点：神策（精细化运营/AB）。
- 召回：FCM 推送 + 站内信 + 系统消息。
- 社交裂变：社区、关注、粉丝榜、赛事造势。
- 多形态内容：文字 + 漫画 + 有声，延长使用时长、覆盖不同消费场景。

## 6. 体验亮点

- 全球化本地化彻底（90+ 语言），可快速进入新市场。
- 内容形态丰富（文/漫/听三合一）。
- 完整 UGC 创作闭环，构建内容供给护城河。
- 变现工具齐全（解锁/批量/等待/广告/充值/Gems）。
- 合规度高（targetSdk 33、权限克制）。

## 7. 潜在短板（推断）

- 第三方 SDK 偏多（多家广告 + 客服 + 社交），包体与隐私合规复杂度上升。
- 重度依赖 Google 生态（Billing/FCM/GMS），在 GMS 缺失市场（如部分华为/中东渠道）需额外适配。
- 社区 + 创作 + 多形态导致首屏与信息架构较重，新用户认知成本可能偏高。

## 8. 对我们的启示（要点）

1. 出海网文的**标准变现三件套**：内购金币解锁 + 激励广告 + 等待解锁，建议直接对标。
2. **本地化是入场券**：架构上一开始就要支持多语言、多币种。
3. **归因 + 埋点先行**：AppsFlyer/Adjust + 自有埋点是买量增长的基础设施。
4. UGC、漫画、有声属于**第二阶段能力**，MVP 不必全做（YAGNI）。
5. 优先打透「文字小说 + 金币解锁 + 激励广告」最小闭环，再叠加留存玩法。

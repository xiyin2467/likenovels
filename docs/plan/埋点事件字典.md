# 埋点事件字典

> 依据：`docs/plan/App架构分配与优化.md` 第 6 节事件清单、`变现模型.md` 监控指标。
> 目的：把事件名扩展为可交付工程的规范——参数、触发时机、所属漏斗，确保上线即可观测。

## 1. 通用约定

- **命名**：小写 + 下划线（`snake_case`），动词在后（`book_click`）。
- **公共参数**（每个事件自动附带）：`user_id`/`device_id`、`session_id`、`platform`、`app_version`、`locale`、`network`、`ts`（毫秒时间戳）。
- **归因参数**（首启与买量相关事件附带）：`media_source`、`campaign`、`af_id`/`adjust_id`。
- **去重**：客户端为每个事件生成 `event_id`（UUID）以便后端去重。
- **实现**：客户端经 `analytics` 模块统一上报；归因走 AppsFlyer/Adjust，行为分析走自有/Firebase。

## 2. 冷启动与账号

| 事件 | 触发时机 | 关键参数 | 漏斗 |
|---|---|---|---|
| `app_open` | App 进入前台 | `is_cold_start`, `source` | 启动 |
| `onboarding_view` | Guide 引导页曝光 | `step`, `step_index` | 激活 |
| `onboarding_select` | 选择性别/口味 | `step`, `choice` | 激活 |
| `onboarding_complete` | 完成引导进入首页 | `selected_genres`, `duration_ms` | 激活 |
| `login_view` | 登录页曝光 | `entry`（guest/forced/profile） | 注册 |
| `login_start` | 点击某登录方式 | `method`（guest/email/google/facebook） | 注册 |
| `login_success` | 登录成功 | `method`, `is_new_user` | 注册 |
| `login_fail` | 登录失败 | `method`, `error_code` | 注册 |

## 3. 发现与内容

| 事件 | 触发时机 | 关键参数 | 漏斗 |
|---|---|---|---|
| `discover_impression` | 书卡进入可视区 | `book_id`, `module`（feed/rank/new/genre）, `position` | 发现 |
| `book_click` | 点击书卡 | `book_id`, `module`, `position` | 发现 |
| `search_start` | 进入搜索 | `entry` | 发现 |
| `search_submit` | 提交搜索词 | `keyword`, `result_count` | 发现 |
| `search_result_click` | 点击搜索结果 | `book_id`, `keyword`, `position` | 发现 |
| `book_detail_view` | 书籍详情曝光 | `book_id`, `source` | 转化 |
| `book_save` | 加入书架 | `book_id` | 留存 |

## 4. 阅读

| 事件 | 触发时机 | 关键参数 | 漏斗 |
|---|---|---|---|
| `chapter_start` | 进入某章阅读 | `book_id`, `chapter_id`, `chapter_index`, `is_free` | 阅读 |
| `chapter_complete` | 读完某章 | `book_id`, `chapter_id`, `read_duration_ms`, `read_ratio` | 阅读 |
| `reader_setting_change` | 调整字号/主题等 | `setting`, `value` | 体验 |
| `catalog_open` | 打开目录 | `book_id` | 体验 |

## 5. 解锁与变现（核心漏斗）

| 事件 | 触发时机 | 关键参数 | 漏斗 |
|---|---|---|---|
| `paywall_view` | 付费墙曝光 | `book_id`, `chapter_id`, `price_coins`, `balance` | 解锁 |
| `unlock_click` | 点击任一解锁方式 | `method`（coins/ad/wait/bulk）, `book_id`, `chapter_id` | 解锁 |
| `unlock_success` | 解锁成功 | `method`, `book_id`, `chapter_id`, `coins_spent` | 解锁 |
| `unlock_fail` | 解锁失败 | `method`, `error_code`（如 insufficient_balance） | 解锁 |
| `wait_unlock_start` | 启动等待解锁倒计时 | `book_id`, `chapter_id`, `wait_hours` | 留存 |
| `wait_unlock_ready` | 倒计时结束可免费解锁 | `book_id`, `chapter_id` | 留存 |
| `reward_ad_start` | 激励视频开始 | `scene`（unlock/earn/checkin）, `placement` | 广告 |
| `reward_ad_complete` | 激励视频完成发奖 | `scene`, `reward_coins`, `ecpm` | 广告 |
| `reward_ad_fail` | 广告加载/播放失败 | `scene`, `error_code` | 广告 |

## 6. 充值与钱包

| 事件 | 触发时机 | 关键参数 | 漏斗 |
|---|---|---|---|
| `recharge_view` | 充值页/弹层曝光 | `entry`（paywall/wallet）, `balance` | 付费 |
| `purchase_start` | 点击某充值档位 | `sku`, `price`, `currency`, `is_first_purchase` | 付费 |
| `purchase_success` | Billing 回调成功 | `sku`, `price`, `currency`, `coins`, `order_id`, `is_first_purchase` | 付费 |
| `purchase_fail` | 支付失败/取消 | `sku`, `error_code` | 付费 |
| `checkin_claim` | 签到领取 | `day_index`, `reward_coins` | 留存 |

## 7. 增长与召回

| 事件 | 触发时机 | 关键参数 | 漏斗 |
|---|---|---|---|
| `push_token_upload` | 上报 FCM token | `permission_status` | 召回 |
| `push_received` | 收到推送 | `push_type`, `book_id?` | 召回 |
| `push_open` | 点击推送进入 | `push_type`, `book_id?`, `deeplink` | 召回 |
| `message_view` | 站内信/消息曝光 | `message_id`, `type` | 召回 |

## 8. 核心漏斗看板（由上述事件拼装）

1. **激活漏斗**：`app_open` → `onboarding_complete` → `login_success`。
2. **发现转化漏斗**：`discover_impression` → `book_click` → `book_detail_view` → `chapter_start`。
3. **解锁漏斗**：`paywall_view` → `unlock_click` →（按 `method` 拆分）→ `unlock_success`。
4. **付费漏斗**：`recharge_view` → `purchase_start` → `purchase_success`（关注 `is_first_purchase`）。
5. **留存漏斗**：`wait_unlock_start` → `wait_unlock_ready` → 次日 `chapter_start`；`push_open` 回访。

## 9. 关键指标映射

- 付费率 = `purchase_success` 去重用户 / 活跃用户。
- 解锁方式占比 = 按 `unlock_success.method` 分组。
- 广告收入健康 = `reward_ad_complete` 人均次数 × 平均 `ecpm`。
- 首充转化 = `purchase_success(is_first_purchase=true)` / `paywall_view` 用户。
- 追更留存 = `wait_unlock_ready` 后次日 `chapter_start` 比例。

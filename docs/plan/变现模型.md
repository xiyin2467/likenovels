# 变现模型

> 对标 GoodNovel 的「金币内购 + 激励广告 + 等待解锁」三件套，结合出海合规设计。
> 实现说明：客户端落地为**两套并行的充值体系**——① 金币充值（消耗型）② 会员订阅（订阅型）。金币充值包不再平铺于钱包页，收纳进 Top-up Sheet（更隐蔽）；钱包页首屏突出「会员」入口以拉动订阅 LTV。

## 1. 收入结构总览

| 收入来源 | 占比预期（推断） | 角色 |
|---|---|---|
| 金币解锁（内购充值，消耗型） | 主（约 55–70%） | 核心利润 |
| 会员订阅（VIP，订阅型） | 增量主力 | 稳定现金流 / 高 LTV |
| 激励视频广告 | 辅（约 20–35%） | 非付费用户变现 + 解锁转化 |

## 2. 虚拟货币体系 & 会员体系

**两套并行体系：**

1. **金币充值（消耗型 / one-time product）**
   - **金币（Coins）**：用真实货币（Google Billing）充值获得，用于解锁付费章节。
   - **赠币/奖励币（Bonus）**：通过签到、看激励视频、新人礼、活动获得，与充值币可设不同消耗规则（如奖励币优先消耗、不可提现）。
   - 充值档位（示例，待本地化定价/AB）：$0.99 / $4.99 / $9.99 / $19.99 / $49.99，越高档赠送比例越高。
   - **入口收敛**：金币 pill / 钱包页 "Top up coins" / Paywall 底部链接 → Recharge Sheet。钱包页不再平铺套餐卡片。

2. **会员订阅（订阅型 / subscription）**
   - **VIP 会员**：Google Play 订阅商品，自动续订，提供长期权益。
   - 权益：免费畅读 VIP 标签作品、免广告、每日自动赠币、新章抢先读、专属徽章。
   - 档位（示例）：Weekly $2.99（+30 币/日）/ Monthly $9.99（+50 币/日，主推）/ Yearly $79.99（+80 币/日，最划算）。
   - **入口**：钱包页显眼的「VIP Membership」金色卡片 → Membership Sheet。
   - **与金币互补**：金币偏「单本即时解锁」的轻度/冲动消费；会员偏「重度读者长期权益」的稳定订阅。两者可叠加（会员每日赠币仍走金币体系消耗）。

## 3. 解锁机制设计

### 3.1 付费墙
- 每本书前 N 章免费（如前 3–10 章），之后进入付费章节。
- 付费墙页提供三个出口：① 金币解锁本章/批量；② 看激励视频免费解锁本章或得币；③ 等待解锁（倒计时后免费）。

### 3.2 等待解锁（Wait-to-unlock）
- 单本书每隔 X 小时（如 4/8/24h）可免费解锁 1 章，倒计时养成定时回访。
- 付费可立即跳过等待，形成"耐心 vs 付费"的选择漏斗。

### 3.3 激励广告
- 场景：付费墙解锁、每日赚币、签到加成。
- 频次与 eCPM 平衡：设每日激励次数上限，避免伤害体验与留存。
- 中介：AppLovin MAX 聚合 AdMob/Unity/ironSource/Mintegral/Vungle，竞价取最高 eCPM。

## 4. 留存与付费转化设计

- **新人期**：充足免费章 + 新人赠币 + 首充优惠，先建立阅读习惯。
- **签到/每日免费金币**：拉动 DAU，制造每日回访理由。
- **追更钩子**：热门书高频更新 + 章末悬念 + 自动解锁顺滑追更。
- **AB 可调参数**：免费章数、解锁单价、等待时长、广告频次、首充礼包——全部埋点可观测、可实验。

## 5. 定价与本地化

- 多币种：按市场用 Google Play 本地化定价（英语市场美元为基准，拉美/东南亚按购买力调整）。
- 金币与本地货币的兑换比例按市场差异化设置。

## 6. 合规要点

- **必须走 Google Play Billing** 做数字内容内购（平台政策强制，违规下架）。
- 广告需接入同意管理（GDPR/CCPA）、遵守 AdMob 家庭政策与广告 ID 规则。
- 价格、自动续费（若做订阅）须清晰披露，支持取消与退款入口。

## 7. 关键监控指标

- 付费率、ARPU、ARPPU、首充转化、复充率。
- 激励广告：人均观看次数、广告 eCPM、广告收入占比。
- 解锁漏斗：付费墙到达率 → 解锁率（付费/广告/等待各占比）。
- LTV 与 LTV/CPI（买量健康度）。
